২
পেমেন্টের মাধ্যম নির্বাচন করুন
অর্ডার ফর্মে bKash অথবা Nagad নির্বাচন করুন। স্ক্রিনে দেখানো পেমেন্ট নম্বরটি মিলিয়ে নিন।
৩
Send Money করুন
bKash/Nagad অ্যাপ খুলে Send Money নির্বাচন করুন। অর্ডারের স্ক্রিনে দেখানো সঠিক নম্বর এবং অ্যাকাউন্টের সঠিক মূল্য লিখে পাঠান। টাকা পাঠানোর আগে প্রাপকের নম্বর ও পরিমাণ আবার যাচাই করুন।
৪
Transaction ID দিন
টাকা পাঠানোর পর পাওয়া আসল Transaction ID এবং যে নম্বর থেকে টাকা পাঠিয়েছেন সেটি অর্ডার ফর্মে লিখুন। ভুয়া Transaction ID দেবেন না।
৫
অর্ডার জমা দিয়ে অপেক্ষা করুন
Submit করার পর My Orders-এ অর্ডারের অবস্থা দেখুন। Admin পেমেন্ট যাচাই না করা পর্যন্ত Payment Pending থাকবে। Approved হওয়া মানেই অ্যাকাউন্টের সব তথ্য যাচাই হয়েছে—এমন ধরে নেবেন না; অর্ডারের চূড়ান্ত অবস্থা দেখুন।
🔒 নিরাপত্তা: PIN, OTP, পাসওয়ার্ড বা Recovery Code কাউকে দেবেন না। টাকা পাঠানোর আগে পেমেন্ট নম্বর নিশ্চিত করুন। ভুল নম্বরে পাঠানো টাকা ফেরত পাওয়ার নিশ্চয়তা নেই। পেমেন্ট করার আগে সন্দেহ হলে অর্ডার করবেন না।
গুরুত্বপূর্ণ: এখানে দেখানো bKash/Nagad নম্বর সাইটের কনফিগারেশনে নির্ধারিত। নম্বরগুলো সঠিক ও আপনার নিয়ন্ত্রণে আছে কি না, মালিক/অ্যাডমিনকে নিশ্চিত করতে হবে।
